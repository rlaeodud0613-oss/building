# 태권도장 AI 운영 비서 MVP

브라우저에서 바로 실행되는 태권도장 출석 자동화 프로토타입입니다.

## 현재 기능
- 학생 명단 관리
- 출석 / 지각 / 결석 체크
- 자연어 명령
  - "오늘 출석 확인해봐"
  - "김민수 출석 처리"
  - "결석자 보여줘"
  - "지각자 보여줘"
  - "전체 출석 처리"
- 오늘 출석률과 결석/지각자 자동 요약
- 학부모 메시지 초안 생성
- 브라우저 LocalStorage 자동 저장
- 출석 데이터 JSON 내보내기

## 실행
GitHub Pages에서 `/dojang-os/` 경로로 접속하거나, `index.html`을 브라우저에서 직접 열면 됩니다.
