# 태권도장 AI 운영 비서 MVP

브라우저에서 바로 실행되는 태권도장 출석 자동화 프로토타입입니다.

## 현재 기능
- 학생 명단 관리
- 출석 / 지각 / 결석 체크
- 자연어 명령
  - "오늘 출석 확인해봐"
  - "김민수 출석 처리"
  - "결석자 보여줘"
  - "지각자 보여줘"
  - "전체 출석 처리"
- 오늘 출석률과 결석/지각자 자동 요약
- 학부모 메시지 초안 생성
- 브라우저 LocalStorage 자동 저장
- 출석 데이터 JSON 내보내기

## 실행
GitHub Pages에서 `/dojang-os/` 경로로 접속하거나, `index.html`을 브라우저에서 직접 열면 됩니다.

## 2026-09 구현 완료: 로컬 운영 버전

기존 HTML·CSS UI에 `core.js`(검증/계산)와 `app.js`(화면/로컬 저장)를 추가했습니다. 루트 `index.html`은 변경하지 않습니다. 위의 초기 MVP 설명과 로드맵은 작업 이력으로 보존합니다.

### 사용 순서
1. `dojang-os` 폴더에서 `python3 -m http.server 8765`를 실행하고 `http://localhost:8765`를 엽니다. HTTPS 정적 호스팅도 가능합니다.
2. 수련생 추가에서 이름, 반, 월 회비, 등록일, 수업 요일을 입력합니다. 연락처는 선택입니다.
3. 출석 관리에서 날짜를 선택하여 출석/지각/결석/공결을 기록합니다. 취소하면 미체크 상태로 돌아갑니다.
4. 회비 관리에서 청구 월을 선택하고 재원생 청구를 생성합니다. 장부 수정에서 누적 수납액·수납일을 기록합니다. **실제 결제 기능은 없습니다.**
5. 상담 CRM에서 단계와 다음 일정을 기록합니다. '수련생 등록'으로 정보를 옮기고 저장하면 등록완료 단계가 됩니다.
6. 학부모 메시지는 초안 생성 → 직접 내용 수정 → 수정 저장 → 복사 순서로 사용합니다. **자동 발송은 없습니다.**
7. 운영 리포트에서 일/주/월과 기준일을 선택하고 텍스트 다운로드를 사용할 수 있습니다.
8. 설정에서 JSON 백업을 정기적으로 내려받습니다. 복원 시 파일 검증·건수 미리보기·적용 확인을 거칩니다. 원래 저장 데이터는 '복원 전 사본 다운로드'로 받을 수 있습니다.

### 기능과 계산 기준
- 수련생: 등록/수정/이름 검색/재원·휴원·퇴원 상태. 삭제 대신 상태를 변경하여 이력을 보존합니다.
- 출석: 한국 날짜(Asia/Seoul), 과거 날짜 기록, 상태 수정/취소. 미래/등록 전 기록은 거절합니다.
- 전체 출석: 해당 날짜에 수업이 있는 재원생 중 미체크만 처리합니다. 기존 지각·결석 기록을 덮어쓰지 않습니다.
- 출석률: `(출석 + 지각) / (출석 + 지각 + 결석)`. 미체크·공결 제외, 기간 통계는 사람 수가 아닌 출석 기록 건수입니다.
- 장기결석: 최근 출석·지각·공결 또는 등록일부터 설정 일수 이상 지났고 그 이후 명시적 결석 기록이 있는 재원생. 기본 7일, 달력 일수 기준입니다.
- 회비: 학생·월별 하나의 청구, 정수 원 단위, 부분 수납 가능, 청구액 초과 수납 거절. 수정 시 누적 수납액을 입력합니다. 회비 변경은 기존 청구액에 소급 적용되지 않습니다.
- 리포트: 주간은 월요일~일요일, 월간은 해당 달 전체. 회비는 기간에 걸친 청구 월의 현재 잔액이며 기간 중 현금흐름 보고서가 아닙니다.
- 자연어: 로컬 규칙 기반이며 외부 AI를 호출하지 않습니다. '김민수 출석 처리', '전체 출석 처리', '장기결석 보여줘', '회비 미납자', '오늘 상담 예정', '주간 리포트', '월간 리포트', '메시지 초안', '백업'을 지원합니다. 동명이인은 자동 처리하지 않습니다.
- 모바일: 반응형 메뉴/카드/폼, 표는 영역 안에서 가로 스크롤합니다. 데스크톱과 별도 기기 사이의 데이터 자동 동기화는 없습니다.

### 데이터 보호와 한계
- LocalStorage 키: `dojang-os:v1`. 복원 전 사본: `dojang-os:v1:before-restore`.
- 초기 샘플 개인정보를 넣지 않습니다. 백업/학생 데이터는 Git에 커밋하지 마세요.
- `connect-src 'none'` CSP로 외부 API 통신을 차단합니다. 외부 폰트·분석 스크립트·발송/결제 SDK가 없습니다.
- 잘못된 저장 데이터를 만나면 원본을 유지하고 쓰기를 중지합니다. 저장 용량 오류는 성공으로 표시하지 않습니다. 다른 탭 변경을 감지하면 새로고침 전까지 쓰기를 중지합니다.
- JSON 백업은 버전/중복 ID/참조/금액/날짜/메시지 초안 상태를 검증합니다. 파일 크기는 5MB 이하로 제한합니다.
- 복원 전 사본은 다음 복원 시 교체되므로 필요한 사본은 별도로 내려받으세요.
- 현재 버전은 단일 브라우저용 로컬 운영 앱입니다. 로그인·암호화·역할 권한·서버 백업·다중 직원 동시편집은 구현하지 않습니다. 실제 개인정보를 대규모 운영하기 전 이러한 별도 보호 설계가 필요합니다.
- 현재 재원 상태/수업 요일은 이력형이 아닙니다. 이미 저장된 출석/회비 기록은 상태 변경 후에도 리포트에 유지되지만 과거 예정 수업표를 복원하지는 않습니다.
- 자동 발송, 실결제, 원격 개인정보 전송, 외부 AI 연결은 의도적으로 포함하지 않았습니다.

### 개발 테스트
Node.js 22.12+ 환경에서:

```sh
cd dojang-os
npm ci
npm test
```

별도 빌드나 서비스 API 키 없이 실행합니다. 테스트에는 가상 수련생만 사용합니다.

### 실제 브라우저 자동 검사

```sh
npm ci
npx playwright install --with-deps chromium webkit
npm run test:browser
```

6가지 실제 사용 흐름을 데스크톱 1440px, 태블릿 768px, 모바일 390px Chromium, 모바일 390px WebKit에서 반복합니다(총 24개). PR 변경 시 GitHub Actions `Dojang OS checks`가 기존 32개 로직/DOM 테스트와 함께 실행됩니다. 가상 수련생만 사용하며 테스트 보고서·출석 화면 캡처는 Actions의 `dojang-browser-results` 결과물에 7일 보관됩니다. WebKit 모바일 모의 실행은 실제 iPhone 하드웨어 테스트와 다릅니다.

처음 사용하는 순서는 [START-HERE.md](./START-HERE.md)를 참고하세요.
