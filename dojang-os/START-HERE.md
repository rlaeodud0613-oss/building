# 처음 사용하는 순서

이 버전은 도장 운영을 한 기기의 브라우저 안에서 관리합니다. 메시지는 초안으로만 만들고 회비는 수납 장부에만 기록합니다.

## 첫 5분
1. **설정 · 백업** → 도장 이름과 장기결석 기준을 저장합니다.
2. **수련생 추가** → 먼저 `테스트학생`을 등록합니다. 반·월 회비·수업 요일을 설정합니다. 실제 연락처는 넣지 않아도 됩니다.
3. **출석 관리** → 테스트학생의 출석·지각·결석을 바꿔 봅니다. `취소`를 누르면 미체크로 돌아갑니다.
4. **회비 관리** → 월을 선택하고 `재원생 청구 생성`을 누릅니다. `장부 수정`에서 누적 수납액을 입력합니다. 결제나 이체가 일어나지 않습니다.
5. **학부모 메시지** → 초안을 만들고 문구를 수정해 저장합니다. 자동으로 보내지 않습니다.
6. **운영 리포트** → 일일·주간·월간을 확인합니다.
7. **설정 · 백업** → `전체 JSON 백업`을 내려받아 안전한 곳에 보관합니다.

## 실제로 쓰기 전
- 테스트 자료는 별도 브라우저 프로필에서 만들면 실제 운영 자료와 분리할 수 있습니다.
- 노트북과 휴대폰의 자료는 자동으로 공유되지 않습니다. 하나의 기기·브라우저를 주 운영 환경으로 정하세요.
- 기기를 바꿀 때는 기존 기기에서 전체 JSON 백업 → 새 기기에서 파일 선택 → 건수 확인 → 복원 적용 순서로 옮깁니다.
- 복원은 새 기기의 현재 자료를 교체합니다. 현재 자료도 먼저 백업하세요.
- 브라우저 방문 기록 삭제 메뉴에서 사이트 데이터를 삭제하면 앱 기록도 사라질 수 있습니다. 매일 운영 종료 후 백업을 권합니다.

## 자주 쓰는 명령
- `테스트학생 출석 처리`
- `전체 출석 처리`
- `결석자 보여줘`
- `회비 미납자 알려줘`
- `오늘 상담 예정 보여줘`
- `장기결석 보여줘`
- `주간 리포트`

이 명령은 미리 정한 규칙으로 처리됩니다. 동명이인 출석은 출석 화면에서 반을 확인하고 직접 처리하세요.

## 현재 지원하지 않는 것
여러 직원의 실시간 공동 작업, 계정 로그인, 서버 자동 백업, 자동 문자·카카오 발송, 실제 결제. 현재 브라우저의 저장 자료만 사용합니다.
